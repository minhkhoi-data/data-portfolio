# Power BI Artifact

Main report file:

`Ecommerce_Growth_Analytics.pbip`

This is a portable Power BI Project (PBIP). The eight analytical CSV tables are
embedded in the semantic-model TMDL partitions, so the report does not depend on
a local file path or a GitHub raw-data URL.

The `screenshots/` folder contains real Power BI Desktop screenshots from a successful
runtime open of this project.

The screenshots include all five report pages plus the Power BI model view.
