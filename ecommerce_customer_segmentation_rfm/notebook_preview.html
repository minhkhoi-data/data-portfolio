## 3. RFM and lifecycle answer different questions RFM uses relative cutoffs with equal raw values receiving equal scores; repeated cutoffs may leave empty bands. R is calendar recency, F distinct positive invoices, M gross purchases minus recorded credits. RFM sum is descriptive, not an action optimizer. Lifecycle uses absolute 90/180-day rules and observed order count. See docs/METHODS.md for all rules and precedence. M affects active, at-risk and dormant treatments. Credit review overrides outreach. Relative labels do not prove loyalty or new acquisition.

## 4. Repeat purchase: the right denominator and window All-history repeat has unequal follow-up. Mature 90-day repeat requires first timestamp + 90 elapsed days <= actual source end. A second invoice at day 90 plus one second is outside the window. Day 0 repeat is possible; compare the another-day definition. The cumulative curve uses the same mature denominator at every point. The repeaters-only median is not an optimal message day. Current RFM group versus historical first-repeat outcome would be circular, so no individual probability is assigned from that comparison.
